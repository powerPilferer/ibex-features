# 리본 루프 v4 — 교체 메모 (모선 10-19)

**정방향 반복이고 핑퐁이 아닙니다.** 끝 장면이 첫 장면으로 그대로 이어지는 9.958초 루프입니다(239프레임, 24fps 원속도, 프레임 보간 없음).
- 사장님 원문: "차라리 10초짜리 영상의 끝나는 부분을 첫씬과 동일하게 끝내서 반복시킬수 있어? 영상을 다시 만들더라도"
- 소스: Kling 2.5 turbo pro i2v로 **같은 그린판을 시작·끝 프레임(tail_image_url)으로 모두 넣어** 새로 생성했습니다. 브리프와 cfg는 2R 원본 페이로드 그대로입니다. 2회 생성(L1·L2) 중 L2를 골랐습니다. 이어서 SeedVR2 ×2(ns .05)로 업스케일한 뒤 v3와 같은 key2k 문법으로 처음부터 다시 키잉했습니다(스트레이트 알파, 언믹스). 색 굽기와 α×.9는 v3와 같아서 필터는 쓰지 않습니다.
- 이음 처리: Kling 클립의 마지막 프레임(=첫 프레임)은 버렸습니다. 끝 4장에는 (첫 프레임 − 238번 프레임) 차이를 고르게 나눠 더해 첫 프레임으로 미끄러져 들어가게 했습니다. 차이 자체가 작아서(합성 MAD 0.64/255) 겹쳐 보이지 않고 미세하게 움직이는 정도입니다.

## RIBBON_SETS 에 넣을 값 (js/top.js — 파일은 안 건드렸음)
```js
// 모선 v4(10-19): 정방향 루프(끝=처음, 핑퐁 아님) 9.958s · Kling tail=첫 프레임 재생성 → SeedVR2 ×2 → 재키잉 · 1.5배 2880×1506 · 색 구움
v4: { dir: 'assets/top/ribbon/v4/', webm: 'ribbon-v4-x15-vp9-M.webm', mov: 'ribbon-v4-x15-hevc-M.mov', poster: 'ribbon-v4-x15-poster.webp',
      enc: [2880, 1506], crop: [0, 16, 1920, 1020], tau0: 0, filter: 'none' }
```
그다음 `RIBBON_USE = 'v4'`로 바꿉니다.
- **crop·enc는 v3와 같습니다.** 그래서 fit 상자도 같은 자리입니다. 첫 프레임 리본은 원본 첫 프레임과 알파 IoU 0.996, 무게중심 차 0.8px 이내입니다.
- **tau0 = 0**: v3의 tau0 4.069는 핑퐁 시간식에서 원본 2.5초 자세를 찾던 값이라 v4에서는 의미가 없습니다. 포스터도 k=0(첫 프레임)입니다. 영상이 첫 프레임에서 시작해 `loop`로 계속 돕니다.
  - 확인이 필요한 점: **지금 페이지의 첫 화면 자세는 원본 2.5초 자세인데, v4는 원본 0초 자세(그린판 그 자체)로 엽니다.** 새 루프 안에는 2.5초 자세와 맞는 프레임이 없습니다(최근접 MAD 14). 첫 장면이 조금 달라 보이면 이 때문입니다.
- **윤곽 `ribbon-outline.json`을 바꿔야 할 수 있습니다.** 옛 윤곽은 "0~5.5초 루프의 합집합"이라 원본 리본이 크게 들려 펼쳐지던 범위까지 들어 있습니다. v4는 덜 들리기 때문에 합집합 IoU가 0.81이고, 문장 띠 근처(원본 y 550~600)에서 왼쪽 경계가 오른쪽으로 약 +166px(원본 좌표) 물러납니다. 같은 식(α>0.3, 옛 윤곽 재현 오차 2.7px)으로 만든 `ribbon-outline-v4.json`을 이 폴더에 두었습니다. 쓰려면 top.js의 fetch 경로를 `assets/top/ribbon/v4/ribbon-outline-v4.json`으로 바꾸면 됩니다. 문장이 드러나는 타이밍이 조금 달라지니 화면에서 함께 확인해 주세요.
- L 단계: `ribbon-v4-x15-vp9-L.webm` / `ribbon-v4-x15-hevc-L.mov`
